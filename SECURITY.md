# Private security reporting

Do not open a public issue or paste credentials, customer data, delivery codes,
TOTP enrollment data, or recovery codes into an issue or pull request.

Private reporting contact: **OWNER MUST CONFIGURE BEFORE PREVIEW ACCESS**.
Until configured, contact the repository owner through an existing private
channel. Provide the affected commit, route, impact and a synthetic reproduction.
Do not test any deployment without the owner's explicit authorization.

This private project is not cleared for real customers or payments. Supported
security fixes target the current main branch. The owner reviews pull requests;
no automated merge or deployment is authorized. See
[Phase 8 review](docs/phase-8-security.md) for findings and verification limits.
