# Noto Sans Bengali

`noto-sans-bengali.woff2` is the unmodified Bengali subset of the variable
Noto Sans Bengali font. It is served locally, without a Google Fonts request.
Latin characters use the system fallback font.

Source: `@fontsource-variable/noto-sans-bengali` version **5.3.0**, file
`files/noto-sans-bengali-bengali-wght-normal.woff2`.

Upstream: <https://github.com/notofonts/bengali>

The copyright notice and SIL Open Font License 1.1 are included in `OFL.txt`.
Retain them when redistributing the font. The source package is not an
application dependency; the application includes only the font asset.
